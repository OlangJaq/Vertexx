# Vertex-Delta Portfolio Website

This is a Vite + React portfolio website for Vertex-Delta Group LTD.

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```

4. Preview the build locally:
   ```bash
   npm run preview
   ```

## Vercel Deployment

- Connect this repository to Vercel.
- Set the root directory to the project root.
- Use the default build command:
  ```bash
  npm run build
  ```
- Output directory:
  ```bash
  dist
  ```

## Notes

- Add real image URLs to the `image` field in `src/data.js` for each project.
- Update director details, testimonials, and contact information as needed.
